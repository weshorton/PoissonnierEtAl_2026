# PoissonnierEtAl_2026
Data and code for analysis in manuscript "CSF1R inhibition plus chemotherapy relieves systemic immune suppression in human metastatic triple negative breast cancer and sensitizes transgenic mammary tumors to anti-PD-1 therapy by relieving resident memory T cell dysfunction"

# Run Instructions

After ensuring all required packages are installed (see below), simply run

`sh run.sh`

And all Rscripts will be executed in order.
